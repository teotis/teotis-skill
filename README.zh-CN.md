# Codex Skill 合集

一组精心整理的 Claude Code 技能，提升工程工作流体验。

[English](README.md)

## 技能列表

### `html` — 可视化交付

将任何任务产出物变成精美的交互式 HTML 页面，自动在浏览器中打开。不用再盯着终端里的原始文字或逐个下载文件——你得到的是真正的视觉审阅体验：在渲染页面上直接批注、用星级打分、一键把结构化反馈复制回 Claude。支持 PDF、DOCX、PPT、图片、Markdown 以及长篇分析文本。

### `grothendieck` — 架构深度分析

用 11 条数学思维原则审视你的代码库，生成交互式评审报告。你会看到一个全局概览矩阵（所有优化机会按收益与成本排列）、附带改前/改后架构对比图的详细建议卡片，以及完整的评审系统来评估每项发现。报告找到的是**非增量式**的改进——不是"把某个方法提取出去"，而是"抽象层级错了，提升之后几十个特殊分支自然消失"。

### `skill-creator` — 构建 & 迭代技能（Anthropic 出品）

由 Claude 背后的公司 Anthropic 创建。一套完整的技能构建工具箱，覆盖全流程：起草技能 → 用测试用例运行 → 对比有技能和无技能的结果 → 在浏览器中并排审阅输出 → 根据反馈改进 → 循环迭代。包含量化基准测试和触发描述优化，确保你的技能在真实场景中稳定触发。
