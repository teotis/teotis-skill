# Codex Skill 合集

一组精心整理的 Claude Code 技能，提升工程工作流体验。

[English](README.md)

## 技能列表

### `html` — 可视化交付

将终端不友好的任务产出物（PDF、DOCX、PPT、图片、Markdown、长篇分析）转化为自包含的暗色主题 HTML 报告，自动在浏览器中打开。支持两种模式：

- **文件审阅模式** — 在渲染页面上框选/点选批注，坐标映射反馈一键复制，基于 Pointer Events 和 localStorage 持久化
- **文本报告模式** — 卡片式布局 + TOC 导航联动 + 决策面板（采纳/思考/驳回）+ 结构化反馈导出

**精华**：把终端里"盯着一大坨文字或下载文件再看"的体验，变成可交互的视觉审阅 — 批注、星级评分、一键将反馈交还给 Claude。

### `grothendieck` — 架构深度分析

将 Grothendieck 的 11 条数学思维原则（上升海、绝对动因、函子性、层论、米田视角等）应用于代码架构分析。生成交互式 HTML 报告，包含：

- 所有优化建议的 **收益 × 重构成本** 散点矩阵
- 详细建议卡片，附带原则溯源标签、Mermaid.js 拓扑演进对比图
- 完整交互评审系统（星级打分、状态标签、结构化反馈导出）

**精华**：找到的是 **非增量式** 的优化机会 — 不是"把这个方法提取出去"，而是"抽象层级根本错了，提升之后 40 个特殊分支自然消失"。

### `skill-creator` — 构建 & 迭代技能（Anthropic 出品）

由 Anthropic（Claude Code 母公司）创建。一套完整的端到端工具箱，覆盖技能创建、测试、基准评估、优化的全生命周期：

- 按渐进式加载（元数据 → 正文 → 捆绑资源）编写 SKILL.md
- 并行测试运行（带技能 vs 无技能对照），量化断言评分
- 基于浏览器的评估查看器，支持并排输出对比与反馈收集
- 盲测 A/B 对比，严谨评估质量差异
- 通过迭代评估循环优化触发描述，提升技能命中率

**精华**：一套严谨的"草拟 → 测试 → 审查 → 改进 → 循环"方法论，配合量化基准，确保技能不会只在几个手选样例上过拟合。

## 目录结构

每个技能遵循标准布局：

```
skill-name/
├── SKILL.md          # YAML frontmatter + Markdown 指令
├── scripts/          # 可执行辅助脚本（Python）
├── references/       # 按需加载的设计规范
└── assets/           # 模板与静态资源
```
